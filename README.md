# PyReo

Write Python in te reo Māori.

PyReo is an open-source transpiler that lets you write Python using te reo Māori keywords.
Designed for kura kaupapa Māori students learning to code.

## Install

```bash
pip install pyreo
```

## Usage

```bash
pyreo run kia_ora.pyreo
```

## Status

Early development — keyword dictionary is a draft and needs review by te reo Māori speakers.
